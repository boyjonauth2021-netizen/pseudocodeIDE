Paper 4 Python subset

Console Python for CIE 9618, matching the constructs used in the Hodder textbook and the Paper 4 mark schemes. Open the Python IDE and press Run. Keywords are coloured, a near-miss such as whle gets a red wavy underline, and typing a name, print( or object. opens a suggestion list. Ctrl+Space opens it again.

The editor rejects import, lambda, comprehensions and decorators. Python has no CASE and no REPEAT…UNTIL: use if / elif and while.

Selection, loops and functions

myValue = int(input("Please enter my value "))
if myValue > 10:
    print("High")
elif myValue < 0:
    print("Negative")
else:
    print("OK")

for counter in range(1, 5):
    print(counter)

def average(total, count):
    return total / count

Lists and a class

marks = [12, 15, 9]
marks.append(18)

class EventItem:
    def __init__(self, name, difficulty):
        self.__name = name
        self.__difficulty = difficulty
    def GetName(self):
        return self.__name

item = EventItem("Sprint", 3)
print(item.GetName())
